# Website SDN Bandarharjo 02 Semarang
Vanilla HTML/CSS/JS + Vite.

## Jalankan
```
npm install
npm run dev      # development
npm run build    # hasil di /dist (siap deploy ke Vercel)
```
## Ganti isi website
Edit **assets/js/data/content.js** (berita, pengumuman, lomba, galeri, kontak, nomor WA, link sosmed).
Foto galeri: taruh di `public/assets/images/galeri/`, lalu isi nama file di field `img`.
Tanda "CONTOH" = data placeholder, ganti dengan data asli sekolah.
